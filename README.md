# SplitEasy 

**Making group expenses easier, one split at a time!**

SplitEasy is a simple C-based group expense management system designed to make splitting shared expenses easier. It helps users calculate individual contributions, track balances, and determine who owes whom.

This project is being developed as part of my journey of learning C programming and exploring problem-solving through real-world applications.

## Project Objective

The main objective of SplitEasy is to simplify the process of dividing expenses among friends, classmates, or groups without having to calculate everything manually.

## Planned Features

- **Participant Management:** Enter the number of people participating in a group.
- **Expense Entry:** Record how much each participant has paid.
- **Total Calculation:** Calculate the total group expenditure.
- **Equal Expense Split:** Determine the equal contribution per person.
- **Balance Calculation:** Identify who owes money and who should receive money.
- **Smart Settlements:** Generate payment suggestions to settle outstanding balances.
